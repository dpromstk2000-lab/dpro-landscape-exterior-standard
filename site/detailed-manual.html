  1. 対象ページ / routeを開く

Detailed Manual 7/10Customer / approval
DPRO 造園・外構 / Target Recovery

TARGET_MISSINGは「止まる」ための安全機構。

対象が見つからない時

  1. bounded target resolveが失敗
  2. TARGET_MISSINGとして進行停止
  3. Nextを無効化
  4. Retryを表示
  5. Guide Center復旧を表示

Retry

対象ページを再読込し、同じStepのroute / selectorを再解決します。

Guide Recovery

Guide Centerへ戻り、作業名から正しい入口を選び直します。

missing target ≠ skip. Missing target = blocking.
