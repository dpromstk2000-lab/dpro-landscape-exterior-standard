Tutorial V1.2.2の対象解決

1. Current route
各Stepで実際の対象ページを開きます。
2. Current target
そのStepで指定された現在のUI対象を待ちます。
3. Scroll / Highlight
対象を画面中央へスクロールし、オレンジ枠で強調します。
4. Bounded resolve
一定時間内に見つからなければ進行を停止します。

Nextは対象が見つかった時だけ有効になります。Backは直前のStepの実対象へ戻り、Resumeは保存されたStepの実対象を再解決します。

TARGET_MISSING / Retry / Guide recovery

対象が見つからない時は TARGET_MISSING としてブロックし、Nextを無効化します。Retryで対象ページを再読込して再解決するか、Guide Centerで復旧へ戻って作業名から入口を選び直してください。

Safety

Start / Resume / Replay / Back / Next / Close / EscはTutorial進捗だけを扱います。Replayが消すのもTutorial進捗だけです。Tutorialは相談送信、見積保存、写真アップロード、完了承認、Demo Prepareなどの業務変更を自動実行しません。

Accessibility

リンクとボタンはキーボードで操作できます。TutorialはEscで閉じ、左右矢印でBack / Next。CloseやEscで閉じても進捗は保持され、Resumeで同じStepから再開できます。タッチ端末ではタップとTutorialカードのドラッグに対応します。
