契約後に管理センターへ入力する項目

事業者

  • テナント表示名
  • Ownerログインメール
  • 事業者連絡先・営業時間
  • 利用Staff一覧

連携

  • LINE Messaging API Channel
  • Turnstile site / secret
  • 公開ドメイン・Origin
  • 必要な通知設定
Secret値はREADY資料・GitHub・チャットへ保存しません。 Cloudflare / Supabase / LINEの各Secret管理画面へ直接登録します。

導入Gate

1. REGISTER
tenant作成 → Owner Auth → landscape_user_access mapping
2. BIND
Production config → Worker Origin → Storage → LINE → Turnstile
3. CHECK
Production System Check → 権限 → signed upload/download → 通知
4. SWITCH
承認後のみ Production Write / Public Inquiry を有効化
